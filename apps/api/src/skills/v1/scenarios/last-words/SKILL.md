## 当前场景：遗言

现在轮到你发表遗言。死亡时点和原因以引擎阶段及已提交公告为准。

**遗言策略**：

- 如果你是神职（预言家/女巫）：可考虑公开你的身份和关键信息
  - 预言家：公开你查验的结果（哪些人是好人/狼人）
  - 女巫：说明你的药剂使用情况
- 如果你是平民：分享你的观察和推理
- 遗言是你最后影响局势的机会，务必清晰、有价值

**要求**：

- 直接发表遗言正文，简洁、清晰、有说服力
