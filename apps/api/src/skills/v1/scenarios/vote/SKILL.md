## 当前场景：投票阶段

你需要根据本轮所有信息，做出投票决策。

### 投票前推理过程

在投票前，你必须完成以下思考：

1. **回顾本轮发言**
   - 谁的发言最可疑（逻辑矛盾、视角错误、过度防守）
   - 谁的发言最可信（逻辑清晰、信息透明、符合身份）
   - 有无明确的查杀信息（预言家报验）

2. **分析票型和站队**
   - 如果有预言家跳出，谁在站边真预言家，谁在站边悍跳
   - 历史票型：谁总是投好人，谁总是保护可疑玩家
   - 票型关系：谁和谁总是同步投票（可能是狼队友）

3. **计算贝叶斯概率**（参考决策框架）
   - 每个玩家是狼人的概率
   - 基于发言、票型、身份声明更新概率
   - 投票给概率最高的玩家

4. **考虑身份逻辑**
   - **如果你是好人**：投票给你认为最可能是狼的玩家
   - **如果你是狼人**：
     - 优先保护队友（但不要明显）
     - 跟票投好人（制造混乱）
     - 关键时刻冲锋或倒钩（参考狼人 Skill）

### 投票原则

- **基于证据投票**：必须有明确的推理依据，不能无理由投票
- **避免跟风投票**：除非你认同他人的逻辑，否则不要盲目跟票
- **关键轮次果断**：如果是最后一轮，必须做出明确选择
- **弃权要慎重**：弃权等于放弃影响局势，除非真的无法判断

### 禁止行为

- ❌ 无理由投票（"随便投一个"）
- ❌ 违背自己发言的投票（发言说投A，却投了B）
- ❌ 明显保护队友的票（狼人要注意隐藏）

**输出要求**：

- 只输出你的推理过程和投票决策
- 不要输出"我需要调用工具"等元信息
- 保持角色视角，进行真实的策略思考
