## 当前场景：投票阶段

你需要根据本轮所有信息，做出投票决策。

### 投票前推理过程

可从以下角度判断，不要求固定步骤：

1. **回顾本轮发言**
   - 谁的发言最可疑（逻辑矛盾、视角错误、过度防守）
   - 谁的发言最可信（逻辑清晰、信息透明、符合身份）
   - 有无明确的查杀信息（预言家报验）

2. **分析票型和站队**
   - 如果有预言家跳出，谁在站边真预言家，谁在站边悍跳
   - 历史票型：谁总是投好人，谁总是保护可疑玩家
   - 票型关系：谁和谁总是同步投票（可能是狼队友）

3. **权衡判断和行动收益**
   - 各人的可能身份及当前不确定性
   - 基于发言、票型、身份声明更新概率
   - 按自己的阵营目标选择，不把身份概率直接等同于投票收益

4. **考虑身份逻辑**
   - **如果你是好人**：投票给你认为最可能是狼的玩家
   - **如果你是狼人**：
     - 优先保护队友（但不要明显）
     - 跟票投好人（制造混乱）
     - 关键时刻冲锋或倒钩（参考狼人 Skill）

### 投票原则

- **同时投票、互不可见**：本轮所有玩家同时举票，你无法看到其他玩家本轮投了谁，只能基于发言推断他们的倾向，不能把推断当成已经发生的事实
- **基于证据投票**：必须有明确的推理依据，不能无理由投票
- **避免跟风投票**：除非你认同他人的逻辑，否则不要盲目跟票
- **关键轮次果断**：如果是最后一轮，必须做出明确选择
- **弃权要慎重**：弃权等于放弃影响局势，除非真的无法判断

### 言行连续性

- 保留自己已经说过的话和投过的票；允许因新信息或明确策略而改票，也允许狼人有意伪装、保队友或冲票。
- 私有理由应说明实际选择，不要无意把此前承诺或尚未发生的投票改写成历史。

**输出要求**：

- 只输出你的推理过程和投票决策
- 不要输出"我需要调用工具"等元信息
- 保持角色视角，进行真实的策略思考

### PK 投票

- 同一白天可以有多轮投票；前一轮已经公布的票型可以用于推理，本轮尚未结束的票型不可见。
- PK 只在系统指定的候选人之间投票，台上候选人不投票，台外存活玩家不能弃票或投台外玩家。
