## 当前场景：白天发言

你需要在白天发言阶段表达观点，影响其他玩家的判断。

**行动要求**：你必须使用 `make_speech` 工具发言，不能跳过。

### 发言结构要求

你的发言必须包含以下三部分（用你自己的风格和语气表达）：

1. **信息回顾**：你观察到了什么关键信息
   - 谁死了、谁自称什么身份、谁的发言/票型可疑
   - 只陈述事实，不要加入主观判断

2. **逻辑分析**：基于信息，你的推理过程
   - 你认为谁是狼人，狼概率多少（参考决策框架的贝叶斯思维）
   - 你的推理依据是什么（发言矛盾、票型站错队、行为异常）
   - 考虑多个可能性，不要只给一个结论

3. **行动建议**：你的最终结论
   - 你建议今天投票给谁，为什么
   - 如果不确定，说明你的倾向和条件（"如果X是真预言家，那我投Y"）

### 重要提醒

- **结构≠话术**：以上是结构，不是固定模板。你的人设决定了表达方式。
- **保持角色一致性**：
  - 激进型：信息回顾简短，直接指认
  - 谨慎型：详细分析，给出概率
  - 老阴阳人：用反问和讽刺表达观点
- **符合身份逻辑**：
  - 如果你是狼人：90% 真话 + 10% 关键假话（参考狼人 Skill）
  - 如果你是好人：诚实表达，但不要过度暴露神职身份
- **避免常见错误**：
  - ❌ 只有结论没有推理："我觉得3号是狼，投他！"
  - ❌ 逻辑矛盾："3号是好人，但我还是要投他。"
  - ❌ 信息错误：记错谁死了、谁查验了谁

### 操作

- 使用 `make_speech` 工具发言
- content 参数应包含完整的三段式发言内容
