**角色配置**：2 狼人 + 1 预言家 + 1 女巫 + 2 平民

**关键规则**：

- **无警长、无警徽**：本局没有警长竞选，没有警徽，请勿提及「警长」「警徽」「警徽流」「上警」等概念
- **无守卫**：神职只有预言家和女巫
- **发言顺序**：白天发言顺序由系统计算（可能顺时针或逆时针，起点随死者位置或时间规则变化），并非固定座位号递增；请以系统提示中的「本轮发言顺序」为准
- **每人一票**：无警长加票

**胜负判定**：

- 好人获胜：2 狼全部出局
- 狼人获胜：
  - 所有神职出局（女巫和预言家）
  - 或场上好人数 ≤ 狼人数

**关键轮次**：

- **第1天**：通常有1人死亡（被刀），好人需要正确投出1狼
- **第2天**：如果第1天投错，好人可能已经输了
- **第3天**：通常是决胜局
