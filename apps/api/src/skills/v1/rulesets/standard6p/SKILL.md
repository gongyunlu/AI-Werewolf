以下规则仅适用于本项目的 standard6p，不能套用其他板型或赛事规则。

**角色配置**：2 狼人 + 1 预言家 + 1 女巫 + 2 平民；无警长、警徽、守卫。

**胜负判定**：先判断狼人是否全部出局，是则好人获胜；否则所有神职（预言家和女巫）或所有平民出局时狼人获胜。**绑票不是终局**：人数持平或狼人更多不直接终局，仍按上述条件继续结算。同夜最后一狼与最后一民一起出局时，好人获胜。

**所有玩家共同知道的角色能力**：

- 狼人夜间可以讨论并提案，最终形成一个狼刀目标；可选择存活的狼队成员自刀。提案和讨论不等于最终落刀。
- 预言家每晚查验一名存活、非本人且此前未查验的玩家，获知其是否为狼人；实际结果只对预言家可见。
- 女巫有一瓶解药和一瓶毒药，每瓶整局只能使用一次，同一晚只能使用其中一种。
- 女巫任何夜晚都不能自救；解药只能救当晚狼刀目标。存活且尚未使用解药时能看到新刀口，用掉解药或死亡后不再获得新刀口，但保留以前合法看到的信息。
- 毒药只能用于其他存活玩家；可以在后续夜晚毒此前用解药救过的目标。被刀的女巫仍可在当晚结算前使用剩余毒药。
- 这些是公开能力规则，不表示你知道女巫的剩药、实际刀口、真实查验或用药目标；玩家公开报出的信息仍属于其声明。

**夜间流程**：狼刀 → 女巫用药（先询问解药，再询问毒药）→ 预言家查验 → 统一结算死亡 → 判断胜负。后续日次、阶段、合法候选以当前引擎提供的回合事实为准。

**白天流程**：

- 天亮公告后，尚未终局时会先询问狼人是否自爆；此时还未公开发言。本板不支持在任意发言时点自爆。自爆使本人出局并跳过本轮发言和投票，仍需按胜负条件结算。
- 发言顺序由系统给出，可能顺时针或逆时针，并非固定座位号递增。每人一票，无警长加票。
- 普通投票可以投任何存活玩家（包括自己）或弃权；同时举票，本轮未结束时不能看到其他人的投票。
- 最高票平票时进行一轮 PK 发言及投票；候选人不投票，其他存活玩家只能投 PK 候选人，不能弃权。再次平票时当日不放逐。
- 夜间死亡仅第一夜有遗言；第二夜起夜间死亡不能发表遗言。白天放逐使用放逐遗言阶段；对局已终止则不继续运行后续阶段。
