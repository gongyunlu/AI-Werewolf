# 识别悍跳狼

> 适用场景：场上有两个人都说自己是预言家，如何识别真假？

---

## 一、悍跳狼的定义

**悍跳狼** = 狼人假冒预言家，试图混淆好人视听

**目标**：

- 识别出哪个"预言家"是假的
- 保护真预言家
- 投票投出悍跳狼

---

## 二、识别悍跳狼的关键信号

### 信号 1：查验结果过于巧合

**悍跳狼的特征**：

- 第一天就报"查杀"（查验某人是狼人）
- 查杀的目标往往是关键好人（例如女巫、守卫）
- 查验结果过于激进，不符合真预言家的谨慎风格

**真预言家的特征**：

- 第一天通常报"金水"（查验某人是好人）或查杀概率较低
- 查验目标有明确理由（例如"这个人发言可疑"）

**示例**：

```
悍跳狼："我第一晚查验了3号位，他是狼人！"
真预言家："我第一晚查验了5号位，他是好人。"

分析：第一天就查杀的概率较低，悍跳狼更可能。
```

---

### 信号 2：逻辑前后矛盾

**悍跳狼的特征**：

- 警徽流设计不合理（警徽流 = 如果我被投出局，按这个顺序查验）
- 前后发言矛盾（例如之前说信任某人，后来又怀疑）

**真预言家的特征**：

- 警徽流设计合理，有明确逻辑
- 发言前后一致

**示例**：

```
悍跳狼："我的警徽流是 5-7，因为他们发言可疑。"
（但他之前说5号位是金水，现在又说可疑）

真预言家："我的警徽流是 3-6，因为他们还没被查验。"
```

---

### 信号 3：过度防守

**悍跳狼的特征**：

- 被质疑时反应过激
- 疯狂为自己辩护
- 攻击质疑者

**真预言家的特征**：

- 被质疑时冷静回应
- 用硬信息（查验结果）说话
- 不会过度情绪化

**示例**：

```
好人质疑："我觉得你是悍跳狼。"

悍跳狼："你才是狼！你在诬陷我！"（过度反应）
真预言家："我有查验结果，你可以看我的警徽流。"（冷静）
```

---

### 信号 4：票型异常

**悍跳狼的特征**：

- 他的支持者中有多个狼人（票型集中）
- 狼队友会疯狂站他的队

**真预言家的特征**：

- 他的支持者是分散的好人
- 票型较为分散

**示例**：

```
悍跳狼的支持者：1号、2号、4号（都是狼人）
真预言家的支持者：3号、5号、6号（都是好人）

分析：票型集中的一方更可能是悍跳狼。
```

---

## 三、识别流程

### Step 1：听发言

- 两个"预言家"都说什么？
- 查验结果是什么？
- 警徽流是什么？

### Step 2：分析查验结果

- 哪个查验结果更合理？
- 哪个查验结果过于巧合？

### Step 3：观察票型

- 谁在支持哪个"预言家"？
- 票型是否异常集中？

### Step 4：交叉验证

- 如果女巫在场，她的用药记录能验证谁是真的吗？
- 如果有人被查杀，他的反应是什么？

---

## 四、应对策略

### 如果识别出悍跳狼

1. **公开质疑**："我认为X是悍跳狼，理由是..."
2. **号召投票**："今天我们应该投X"
3. **保护真预言家**："Y是真预言家，我们要保护他"

### 如果无法识别

1. **观察票型**：看谁在支持谁
2. **等待更多信息**：第二天可能会有更多线索
3. **相信硬信息**：女巫的用药记录、守卫的守护记录

---

## 五、常见陷阱

### 陷阱 1：先入为主

- **错误**：第一个跳出来的就是真预言家
- **正确**：不要被顺序影响，要看查验结果和逻辑

### 陷阱 2：过度信任

- **错误**：某个"预言家"说得很有道理，就一定是真的
- **正确**：狼人也会编造有道理的谎言

### 陷阱 3：忽略票型

- **错误**：只听发言，不看票型
- **正确**：票型是最诚实的信息

---

## 六、成功案例

### 示例：标准 6 人局

```
第一天白天：
- 1号跳预言家："我查验了3号，他是狼人！"
- 3号跳预言家："我查验了1号，他是狼人！"

分析：
- 1号的查验结果过于激进（第一天就查杀）
- 3号的发言更冷静，逻辑更清晰
- 票型：1号的支持者是2号、4号（疑似狼队友）

结论：1号是悍跳狼

投票阶段：
- 投票投出1号（悍跳狼）
- 保护3号（真预言家）
```

---

## 总结

**识别悍跳狼的核心**：

- ✅ 查验结果是否过于巧合？
- ✅ 逻辑是否前后一致？
- ✅ 被质疑时是否过度防守？
- ✅ 票型是否异常集中？
- ⚠️ 不要先入为主，要综合分析
