# 识别倒钩狼

> 适用场景：场上有人装好人，如何识别他是倒钩狼？

---

## 一、什么是倒钩狼

**倒钩狼** = 狼人不跳身份，假装是好人或平民，混入好人阵营

**特征**：

- 表面上在分析，实际在误导
- 关键时刻票型站错队
- 暗中保护狼队友

---

## 二、识别倒钩狼的关键信号

### 信号 1：票型异常

**倒钩狼的特征**：

- **关键时刻站错队**：当大家投狼人时，他投好人
- **连续站错队**：不是偶尔一次，而是多次
- **为狼队友投票辩护**："我觉得X不是狼，我们应该投Y"

**真好人的特征**：

- 票型大多站对队
- 偶尔站错是因为信息不足，但会调整

**示例**：

```
第一天：投票投狼人时，倒钩狼投了好人
第二天：投票投狼人时，倒钩狼又投了好人
第三天：倒钩狼继续站错队

分析：连续站错队，高概率是倒钩狼
```

---

### 信号 2：发言模式

**倒钩狼的特征**：

- **看似在分析，实际没内容**："我觉得X和Y都可疑，不知道投谁"
- **总是为某人开脱**："虽然X发言可疑，但我觉得他可能是好人"
- **制造混乱**："A说投X，B说投Y，我们到底投谁？"

**真好人的特征**：

- 分析有实质内容
- 有明确的判断和理由
- 不会总是为同一个人开脱

**示例**：

```
倒钩狼："虽然1号被预言家查杀，但我觉得2号更可疑"
（实际：1号是队友，倒钩狼在转移注意力）

真好人："1号被预言家查杀，今天就投他"
（真好人相信硬信息）
```

---

### 信号 3：行为矛盾

**倒钩狼的特征**：

- **前后不一致**：之前说信任某人，后来又质疑
- **过度关注某人**：总是在讨论某个狼队友
- **关键时刻反水**：之前支持预言家，关键时刻却质疑

**真好人的特征**：

- 前后逻辑一致
- 关注的是整体局势，不是某个人

**示例**：

```
倒钩狼第一天："我相信预言家"
倒钩狼第二天："我觉得预言家可能是悍跳狼"
（行为矛盾，可能是倒钩狼）
```

---

### 信号 4：保护队友的方式

**倒钩狼的特征**：

- **不直接说"X不是狼"**（太明显）
- **转移注意力**："虽然X可疑，但我觉得Y更可疑"
- **找借口**："X发言虽然有问题，但可能是他不擅长表达"

**真好人的特征**：

- 不会刻意保护某人
- 分析客观，不带偏向

**示例**：

```
倒钩狼："虽然1号被预言家查杀，但预言家也可能是悍跳狼啊"
（为队友1号辩护）

真好人："1号被预言家查杀，概率很大是狼"
（客观分析）
```

---

## 三、识别流程

### Step 1：回顾票型

- 这个人之前投了谁？
- 关键时刻站对队了吗？
- 连续站错队的概率是多少？

### Step 2：分析发言

- 他的分析有实质内容吗？
- 他总是在为某人开脱吗？
- 他的逻辑前后一致吗？

### Step 3：观察行为

- 他过度关注某个人吗？
- 他的行为有矛盾吗？
- 关键时刻他的选择是什么？

### Step 4：交叉验证

- 如果他一直为X辩护，X后来被证实是狼，那他高概率也是狼
- 如果他连续站错队，且发言无实质内容，高概率是倒钩狼

---

## 四、应对策略

### 如果识别出倒钩狼

1. **公开质疑**："X号位连续站错队，发言也有问题，我怀疑他是倒钩狼"
2. **号召投票**："今天我们投X号位"
3. **观察他的反应**：真好人会冷静解释，倒钩狼可能会过度防守

### 如果无法确定

1. **继续观察**：再看一两轮
2. **记录行为**：记住他的票型和发言
3. **等待更多信息**：预言家可能会查验他

---

## 五、倒钩狼的常见套路

### 套路 1：第一天站对队，后续站错队

```
第一天：投票投狼人（获取信任）
第二天：投票投好人（开始误导）
第三天：投票投好人（继续误导）
```

**应对**：不要因为他第一天站对队就完全信任，看整体表现

### 套路 2：假装分析，实际混乱

```
"我觉得A、B、C都可疑，不知道投谁"
（看似在分析，实际在制造混乱）
```

**应对**：看他的分析是否有实质内容，是否有明确判断

### 套路 3：适度质疑队友，不过度保护

```
"虽然1号确实可疑，但我觉得2号更可疑"
（适度质疑队友1号，实际转移到好人2号）
```

**应对**：看他是否总是转移注意力

## 六、成功案例

### 示例：标准 6 人局

```
第一天白天：
- 预言家查杀1号（狼人）
- 投票：2号投了1号，获取信任
- 1号被投出局

第二天白天：
- 预言家查杀3号（狼人）
- 2号："虽然3号被查杀，但我觉得4号更可疑"
- 投票：2号投了4号（好人）

第三天白天：
- 好人回顾：2号第一天站对队，第二天站错队
- 好人分析：2号第二天为3号辩护，转移到4号
- 好人结论：2号是倒钩狼

投票阶段：
- 投出2号（倒钩狼）
- 狼人全部出局，好人获胜
```

---

## 七、常见误判

### 误判 1：好人偶尔站错队

- **问题**：把偶尔站错队的好人当成倒钩狼
- **正确做法**：看整体表现，不要因为一次站错就认定

### 误判 2：新手玩家

- **问题**：新手不会玩，经常站错队，但不是狼
- **正确做法**：结合发言和行为综合判断

### 误判 3：信息不足的好人

- **问题**：好人因为信息不足而站错队
- **正确做法**：看他站错队后是否调整

---

## 总结

**识别倒钩狼的核心**：

- ✅ 回顾票型（连续站错队）
- ✅ 分析发言（看似分析，实际误导）
- ✅ 观察行为（为某人开脱、制造混乱）
- ✅ 交叉验证（多个信号综合判断）
- ⚠️ 不要因为一次站错队就认定
- ⚠️ 看整体表现，不要单点爆破
