# 识别自刀狼

> 适用场景：有人声称"被狼刀了，但被女巫救了"，如何识别他是自刀狼？

---

## 一、什么是自刀狼

**自刀狼** = 狼人让队友刀自己，骗取女巫解药，并获取好人信任

**特征**：

- 声称"被狼刀了，被女巫救了"
- 利用这个身份获取信任
- 后续行为异常

---

## 二、识别自刀狼的关键信号

### 信号 1：刀口选择异常

**自刀狼的特征**：

- **刀口不合理**：为什么狼人要刀这个人？他很重要吗？
- **没有明确价值**：这个人没有跳神职，没有发表关键言论
- **时机奇怪**：通常是第一晚（女巫盲救的概率高）

**真被刀的特征**：

- 刀口合理：神职、关键好人
- 有明确价值：发言好、分析强

**示例**：

```
第一晚：1号位被刀
分析：1号位第一天还没发言，为什么狼人要刀他？
可能：1号位是自刀狼
```

---

### 信号 2：被救后过度表现

**自刀狼的特征**：

- **过度感谢女巫**："感谢女巫救我，我一定是好人"
- **过度强调身份**："我被狼刀了，说明我不是狼"
- **主动提及**：反复提及"我被刀了"

**真被刀的特征**：

- 感谢女巫，但不过度
- 不会反复强调"我不是狼"

**示例**：

```
自刀狼："我被狼刀了，被女巫救了，所以我一定是好人！"
（过度强调）

真被刀的好人："我被刀了，感谢女巫。我们继续分析..."
（简单提及，继续分析）
```

---

### 信号 3：后续行为异常

**自刀狼的特征**：

- **票型站错队**：被救后，投票时站错队
- **发言误导**：看似分析，实际误导
- **保护队友**：为其他狼人辩护

**真被刀的特征**：

- 票型正常
- 发言有价值
- 不会刻意保护某人

**示例**：

```
第一天：1号被刀，被救
第二天：1号投票站错队，投了好人
第三天：1号继续站错队

分析：被救后连续站错队，可能是自刀狼
```

---

### 信号 4：女巫的判断

**女巫的视角**：

- **为什么他会被刀？**：这个人有什么价值？
- **他的后续表现如何？**：被救后是否异常？
- **我要不要公开？**：如果怀疑是自刀，要不要揭穿？

**女巫的策略**：

- 第一晚不要盲救可疑玩家
- 如果救了，后续密切观察
- 如果确认是自刀，可以公开揭穿

---

## 三、识别流程

### Step 1：分析刀口

- 为什么狼人要刀这个人？
- 这个人有什么价值？
- 刀口是否合理？

### Step 2：观察表现

- 被救后如何发言？
- 是否过度强调"我不是狼"？
- 是否过度感谢女巫？

### Step 3：观察票型

- 被救后的票型如何？
- 是否站对队？
- 是否有保护某人的行为？

### Step 4：交叉验证

- 如果刀口不合理 + 过度表现 + 票型异常，高概率是自刀狼
- 如果只有一个信号，不足以判断

---

## 四、应对策略

### 如果女巫怀疑自刀

1. **不要救**：第一晚如果觉得刀口不合理，可以不救
2. **观察后续**：如果救了，密切观察被救者的表现
3. **公开揭穿**：如果确认是自刀，可以公开："我救了X号，但他可能是自刀狼"

### 如果好人怀疑自刀

1. **回顾刀口**：为什么狼人要刀他？
2. **观察表现**：被救后的发言和票型
3. **预言家查验**：建议预言家查验被救者
4. **公开质疑**："X号可能是自刀狼，理由是..."

---

## 五、自刀狼的常见套路

### 套路 1：第一晚自刀，获取信任

```
第一晚：自刀
第二天：获取信任，开始误导
第三天：利用信任，带节奏投掉关键好人
```

**应对**：不要因为"被刀了"就完全信任，看后续表现

### 套路 2：假装震惊，过度表现

```
"天哪，我被刀了！幸好女巫救了我！"
"我一定是好人，不然狼人为什么要刀我？"
```

**应对**：观察他是否过度强调身份

### 套路 3：利用信任，误导投票

```
"我是被狼刀的好人，我觉得X号很可疑，今天投他"
（利用"被刀"的身份误导投票）
```

**应对**：看他的分析是否合理，不要盲目相信

## 六、成功案例

### 示例：标准 6 人局

```
第一晚：
- 1号被刀，女巫救了

第一天白天：
- 1号："我被狼刀了，被女巫救了，我一定是好人！"
- 女巫心理：为什么狼人第一晚要刀1号？他还没发言，没有价值

第二天白天：
- 1号投票站错队，投了好人
- 女巫分析：刀口不合理 + 过度表现 + 票型异常 = 自刀狼
- 女巫公开："我第一晚救了1号，但我怀疑他是自刀狼"

第三天白天：
- 预言家查验1号，确认是狼人
- 好人投出1号（自刀狼）
```

## 七、女巫的防范策略

### 策略 1：第一晚谨慎救人

- **不要盲救**：如果刀口不合理，可以不救
- **观察价值**：被刀的人有什么价值？

### 策略 2：密切观察被救者

- 记录被救者的后续表现
- 观察票型和发言
- 如果异常，及时揭穿

### 策略 3：配合预言家

- 如果怀疑自刀，建议预言家查验
- 如果预言家查验确认是狼，公开揭穿

---

## 八、常见误判

### 误判 1：真好人被刀

- **问题**：把真被刀的好人当成自刀狼
- **正确做法**：看后续表现，不要单凭刀口判断

### 误判 2：刀口恰好不合理

- **问题**：狼人有时会故意刀价值低的人
- **正确做法**：结合后续表现综合判断

### 误判 3：好人过度感谢

- **问题**：有些好人被救后确实很激动
- **正确做法**：看整体行为，不要单点爆破

---

## 总结

**识别自刀狼的核心**：

- ✅ 分析刀口是否合理
- ✅ 观察被救后是否过度表现
- ✅ 观察后续票型和发言
- ✅ 交叉验证（刀口 + 表现 + 票型）
- ⚠️ 女巫第一晚谨慎救人
- ⚠️ 不要单凭一个信号判断
