# 女巫毒杀战术

> 适用场景：女巫如何正确使用毒药，最大化价值

---

## 一、什么是女巫毒杀

**女巫毒杀** = 女巫在夜间使用毒药毒死一个玩家

**目标**：

1. 毒死确认的狼人
2. 在关键时刻改变局势
3. 不要浪费毒药在好人身上

---

## 二、何时使用毒药

### 最佳时机

#### 1. 确认的狼人

- **预言家查杀的狼人**：硬信息，可以毒
- **明显的悍跳狼**：通过发言、票型确认是狼

#### 2. 高概率是狼的情况

- **多个信号指向同一个人**：
  - 发言矛盾
  - 票型站错队
  - 过度保护某人
  - 预言家怀疑

#### 3. 关键时刻

- **最后一个夜晚**：好人和狼人数量接近，必须毒死狼人
- **己方关键好人被刀**：用毒药平衡局势

### 避免使用的时机

- **信息不足时**：不确定对方是狼就不要毒
- **已经有人被投出局**：那个人可能就是狼，不需要再毒
- **毒药是最后的底牌**：有时保留毒药比用掉更有威慑力

---

## 三、毒杀的决策流程

### Step 1: 收集信息

- 预言家的查验结果
- 票型分析（谁投了谁）
- 发言分析（谁说了什么）
- 行为模式（谁在保护谁）

### Step 2: 计算概率

为每个可疑玩家打分：

**加分项**（增加狼概率）：

- 被预言家查杀：+50 分
- 明显悍跳：+40 分
- 票型站错队：+20 分
- 发言矛盾：+15 分
- 过度防守：+10 分

**减分项**（降低狼概率）：

- 被预言家发金水：-50 分
- 票型站对队：-20 分
- 发言有价值：-10 分

### Step 3: 做决策

- **总分 ≥ 60**：高概率是狼，可以考虑毒
- **总分 40-59**：中等概率，谨慎决策
- **总分 < 40**：低概率，不要毒

---

## 四、毒杀的执行要点

### 1. 不要急于用毒

- **第一晚不要毒**：信息太少，容易误毒
- **等待更多信息**：至少第二天有预言家查验结果后再考虑

### 2. 毒明确的狼

- **预言家查杀的狼**：最安全的选择
- **明显的悍跳狼**：通过多个维度确认

### 3. 毒后保持沉默

- **不要公开你毒了谁**：避免狼人识别你是女巫
- **等白天观察**：看对方是否真的是狼

## 五、常见毒杀场景

### 场景 1: 预言家查杀

```
预言家："我查验了3号位，他是狼人"
女巫心理：预言家的硬信息，可以毒

决策：毒3号位
```

### 场景 2: 明显的悍跳狼

```
1号跳预言家："我查验了3号位，他是狼人"
3号跳预言家："我查验了1号位，他是狼人"

分析：
- 1号的查验结果过于激进
- 1号被多人质疑
- 票型显示1号有狼队友支持

女巫心理：1号高概率是悍跳狼

决策：毒1号位
```

### 场景 3: 多个信号指向

```
2号位：
- 第一天票型站错队（投了好人）
- 第二天发言矛盾（前后不一致）
- 过度保护4号位（可能是队友）

女巫心理：2号位多个信号，中高概率是狼

决策：如果信息足够，可以考虑毒2号位
```

## 六、毒杀的风险控制

### 风险 1: 误毒好人

**后果**：浪费毒药，减员好人，帮了狼人

**控制方法**：

- 只毒高概率是狼的人（概率 ≥ 60%）
- 等待更多信息（不要急于用毒）
- 交叉验证（多个维度确认）

### 风险 2: 暴露身份

**后果**：狼人知道你是女巫，优先刀你

**控制方法**：

- 毒后保持沉默
- 不要公开毒了谁
- 行为低调

### 风险 3: 浪费毒药

**后果**：在不关键的时刻用掉毒药，关键时刻没有

**控制方法**：

- 评估是否是关键时刻
- 有时保留毒药比用掉更有价值
- 威慑作用：狼人不知道你有没有毒药

## 七、关键原则

### 1. 只毒明狼

- **明狼** = 明确是狼人的人（预言家查杀、明显悍跳）
- **不要毒疑似狼**：概率不够高就不要毒

### 2. 信息优先

- 等待更多信息再决策
- 不要在第一晚盲毒

### 3. 关键时刻原则

- 评估当前局势
- 如果是关键时刻，即使概率中等也可以毒
- 如果不是关键时刻，可以再等等

### 4. 保护自己

- 毒后保持沉默
- 不要暴露身份

## 九、常见错误

### 错误 1: 盲毒

- **问题**：第一晚没有信息就毒人
- **正确做法**：等待信息，至少第二晚再考虑

### 错误 2: 毒不确定的人

- **问题**：只有 30-40% 概率是狼就毒了
- **正确做法**：只毒高概率是狼的人（≥ 60%）

### 错误 3: 过早暴露

- **问题**：公开说"我是女巫，我毒了X"
- **正确做法**：保持沉默，不要暴露身份

### 错误 4: 浪费毒药

- **问题**：在不关键的时刻用掉毒药
- **正确做法**：评估是否是关键时刻
