# 预言家带队战术

> 适用场景：预言家跳出身份后，如何指挥好人阵营获胜

---

## 一、什么是预言家带队

**预言家带队** = 预言家公开身份后，利用查验信息指挥好人投票

**目标**：

1. 利用查验信息找出狼人
2. 指挥好人正确投票
3. 保护关键好人（女巫、守卫）

---

## 二、何时跳出身份

### 最佳时机

- **第一天白天**：有了第一晚的查验结果后
- **查到狼人时**：立即跳出来报查杀
- **悍跳狼出现时**：必须跳出来对抗

### 避免的时机

- 还没查验到有价值信息时（可以再等一晚）
- 明确会被狼刀时（先保命，后续再跳）

---

## 三、跳出后的执行要点

### 1. 清晰报告查验结果

```
"我是预言家，昨晚查验了X号位，他是狼人（查杀）"
或
"我是预言家，昨晚查验了X号位，他是好人（金水）"
```

### 2. 设计警徽流

**警徽流** = 如果我被投出局，按这个顺序查验

示例：

```
"我的警徽流是 3-5"
意思：如果我被投出局，优先查验3号位，再查验5号位
```

**设计原则**：

- 把最可疑的人放在前面
- 把还没查验过的关键位置放进去
- 不要把已经查验过的人放进去

### 3. 指挥投票

```
"今天我们投X号位，他是我查验的狼人"
"Y号位是我的金水，大家不要投他"
```

### 4. 分析局势

- 告诉好人当前还剩几个狼
- 距离胜利还有几步
- 哪些人可疑

---

## 四、应对悍跳狼

### 当有人悍跳（假冒预言家）时

**对比查验结果**：

```
真预言家："我查验了3号位，他是好人"
悍跳狼："我查验了3号位，他是狼人"
```

**揭穿对方**：

- 指出对方查验结果不合理
- 指出对方逻辑前后矛盾
- 呼吁好人相信你

**保持冷静**：

- 不要情绪化
- 用硬信息（查验结果）说话
- 不要过度防守

---

## 五、保护自己

### 被狼刀的风险

预言家是狼人的首要目标

**保护策略**：

1. **依靠女巫**：女巫可能会保护你
2. **依靠守卫**（如果有）：守卫会守护你
3. **低调行事**：如果还没查到关键信息，可以先不跳

### 被投出局的风险

悍跳狼可能带节奏投你

**应对策略**：

1. **清晰报告查验**：让好人相信你
2. **分析悍跳狼的漏洞**：指出对方不合理之处
3. **呼吁好人理性判断**：不要被带节奏

---

## 六、关键原则

### 1. 查验策略

- **优先查可疑玩家**：发言矛盾、票型异常的人
- **不要查金水玩家**：浪费查验机会
- **记录查验历史**：白天公开时要清晰报告

### 2. 发言技巧

- **清晰简洁**："我查验了X号位，他是狼人"
- **逻辑清晰**："我为什么查验他？因为..."
- **不要过度**：不要喋喋不休，说重点

### 3. 指挥原则

- **果断**："今天投X号位"
- **解释理由**："因为他是我查验的狼人"
- **接受质疑**：有人质疑时冷静回应

---

## 七、成功案例

### 示例：标准 6 人局

```
第一晚：
- 预言家查验1号位，发现是狼人

第一天白天：
- 预言家跳出："我是预言家，查验了1号位，他是狼人"
- 1号（狼人）悍跳："我才是预言家，查验了3号位，他是狼人"
- 预言家冷静分析："1号的查验结果不合理，他是悍跳狼"
- 好人投票投出1号（狼人）

第二晚：
- 预言家查验2号位，发现是狼人

第二天白天：
- 预言家："2号位是狼人，今天投他"
- 好人投票投出2号（狼人）

结果：
- 两个狼人被投出局
- 好人阵营获胜
```

---

## 八、常见错误

### 错误 1：过早跳出

- **问题**：还没查到有价值信息就跳出来，容易被狼刀
- **正确做法**：至少有一个查杀或关键金水再跳

### 错误 2：报告不清晰

- **问题**："我昨晚查了...呃...好像是3号...还是4号？"
- **正确做法**：清晰报告"我查验了3号位，他是狼人"

### 错误 3：过度防守

- **问题**：被质疑时疯狂辩解，反而像狼
- **正确做法**：冷静回应，用查验结果说话

### 错误 4：不指挥投票

- **问题**：报完查验就不说话了
- **正确做法**：明确指挥"今天投X号位"

---

## 总结

**预言家带队的核心**：

- ✅ 清晰报告查验结果
- ✅ 设计合理的警徽流
- ✅ 果断指挥投票
- ✅ 应对悍跳狼
- ✅ 保护自己
- ⚠️ 不要过早跳出，不要过度防守
