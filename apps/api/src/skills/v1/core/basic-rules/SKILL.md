# 狼人杀基础规则

本文档介绍狼人杀游戏的基础规则、流程和术语。

## 游戏目标

### 好人阵营胜利条件

- **屠狼**：所有狼人出局
- **或** 满足特殊胜利条件（某些板子）

### 狼人阵营胜利条件

- **屠边**：所有神职出局，或所有平民出局
- **或** 场上好人数量 ≤ 狼人数量

## 游戏流程

### 一局游戏的完整流程

```
第1天
├─ 夜间阶段
│  ├─ 狼人刀人
│  ├─ 预言家查验
│  └─ 女巫用药
├─ 白天阶段
│  ├─ 法官宣布死讯
│  ├─ 死者遗言（如果有）
│  ├─ 发言讨论
│  └─ 投票放逐
└─ 检查胜负

第2天
├─ 夜间阶段
├─ 白天阶段
└─ 检查胜负

...（重复直到一方获胜）
```

### 夜间阶段

**行动顺序**（标准板子）：

1. **狼人刀人**：狼人睁眼，讨论并选择刀杀目标
2. **预言家查验**：预言家查验一名玩家的身份
3. **女巫用药**：女巫决定是否使用解药或毒药
4. **守卫守护**（如果有守卫）：守卫选择守护一名玩家

**重要规则**：

- 夜间所有人闭眼，只有当前行动的角色睁眼
- 狼人之间可以互相认识
- 其他角色不知道彼此身份

### 白天阶段

**流程**：

1. **法官宣布死讯**：公布昨晚死亡的玩家
2. **遗言**：死者发表最后的发言（首夜除外）
3. **发言讨论**：存活玩家按顺序发言
4. **投票放逐**：投票选出一名玩家放逐
5. **放逐遗言**：被放逐的玩家发表遗言
6. **检查胜负**：判断游戏是否结束

**发言顺序**：

- 如果有警长：警长决定发言顺序（从左手或右手开始）
- 如果无警长：按照座位号顺序发言

**投票规则**：

- 每人一票（警长1.5票）
- 得票最多的玩家被放逐
- 平票时进入PK环节

### PK（平票）流程

当投票平票时：

1. **PK发言**：平票的玩家各自发言
2. **PK投票**：其他玩家在平票玩家中选择
3. **如果再次平票**：当天无人出局

## 角色介绍

### 狼人阵营

#### 狼人

- **人数**：通常2-4人（根据板子）
- **技能**：每晚杀死一名玩家
- **特点**：知道所有队友身份

### 好人阵营

#### 预言家（神职）

- **技能**：每晚查验一名玩家的身份（好人/狼人）
- **特点**：拥有信息优势，但容易被狼人刀杀

#### 女巫（神职）

- **技能**：
  - **解药**：一局一次，救活当晚被刀的玩家
  - **毒药**：一局一次，毒杀一名玩家
- **特点**：同一晚只能使用一种药

#### 守卫（神职，部分板子）

- **技能**：每晚守护一名玩家，被守护的玩家免疫狼刀
- **特点**：不能连续守护同一人

#### 猎人（神职，部分板子）

- **技能**：出局时可以开枪带走一名玩家
- **特点**：被毒或殉情时不能开枪

#### 平民

- **技能**：无特殊技能
- **特点**：通过逻辑分析和发言找出狼人

## 核心术语

### 身份相关

- **神职**：拥有特殊技能的好人（预言家、女巫、守卫、猎人等）
- **平民**：无特殊技能的好人
- **金水 / 银水**：被预言家查验为好人的玩家（金水）或被狼人刀但被救活的玩家（银水）
- **查杀**：被预言家查验为狼人的玩家
- **悍跳**：狼人假冒神职（通常是预言家）

### 行动相关

- **刀**：狼人杀人的行动
- **查验**：预言家查看身份的行动
- **守护**：守卫保护玩家的行动
- **投票 / 放逐**：白天投票出局玩家
- **自爆**：狼人主动公开身份，结束白天发言

### 战术相关

- **冲锋**：狼人明确站边悍跳狼，公开对抗好人
- **倒钩**：狼人站边真神职，隐藏身份
- **自刀**：狼人刀自己队友，制造银水或骗解药
- **悍跳**：狼人假冒预言家

### 发言相关

- **跳身份**：公开声称自己是某个角色
- **站边**：选择相信某一方
- **表水**：平民通过发言证明自己是好人
- **警徽流**：预言家留下的下一步查验计划

### 投票相关

- **归票**：最后发言者统一票型
- **冲票**：集体投票给某人
- **压票**：不上票，观望局势
- **平票**：多名玩家得票相同，进入PK

## 6人局特殊规则

**角色配置**：2狼人 + 1预言家 + 1女巫 + 2平民

**特点**：

- **快节奏**：通常3-4天结束
- **无警长竞选**：直接进入发言
- **无守卫**：神职只有预言家和女巫
- **容错率低**：好人几乎不能错票

**胜负判定**：

- 好人获胜：2狼全部出局
- 狼人获胜：
  - 所有神职出局（女巫和预言家）
  - 或场上好人数 ≤ 狼人数

**关键轮次**：

- **第1天**：通常有1人死亡（被刀），好人需要正确投出1狼
- **第2天**：如果第1天投错，好人可能已经输了
- **第3天**：通常是决胜局

## 12人局特殊规则

**角色配置**：4狼人 + 预言家 + 女巫 + 守卫 + 猎人 + 4平民

**特点**：

- **有警长竞选**：第一天上警竞选警长
- **警徽流**：预言家留下查验计划
- **复杂站队**：多方势力，需要长线布局
- **容错率高**：好人有一定犯错空间

**警长机制**：

- **选举**：第一天自愿上警，其他人投票
- **权力**：1.5票 + 决定发言顺序 + 传警徽（死亡时）

## 出局方式

### 主动出局

- **被狼刀**：夜间被狼人杀死
- **被毒**：被女巫毒药毒死
- **被投票放逐**：白天投票出局
- **被猎人射杀**：被猎人开枪带走

### 特殊出局

- **自爆**：狼人主动公开身份，立即出局
- **殉情**（特殊板子）：恋人一方死亡，另一方殉情

## 遗言规则

**有遗言**：

- 夜间死亡（被刀、被毒等）
- 被投票放逐

**无遗言**：

- 首夜死亡（通常）
- 自爆
- 被猎人射杀（部分板子）
