# 核心决策框架

本框架提供狼人杀游戏中的通用决策方法论，适用于所有角色和场景。

## 贝叶斯思维

在狼人杀中，你需要根据不断更新的信息调整对每个玩家身份的判断。

**核心公式**：

```
P(狼人|发言) = P(发言|狼人) × P(狼人) / P(发言)
```

**应用方法**：

1. **初始概率**：游戏开始时，每个玩家是狼人的概率 = 狼人数量 / 总人数
2. **更新概率**：每次获得新信息后，更新你对每个玩家的身份判断
3. **综合判断**：基于累积的概率做出决策

**示例**（6人局，2狼）：

- 初始：每个玩家是狼人的概率 = 2/6 ≈ 33%
- 3号发言破绽：P(狼人|破绽发言) 提升到 60%
- 5号被预言家验金水：P(狼人|金水) 降到 5%

## 三段式发言结构

所有发言都应该遵循清晰的三段式结构：

### 1. 信息回顾（What）

陈述你观察到的关键信息：

- 谁说了什么
- 谁做了什么行动
- 发生了什么事件

**示例**：

> "昨晚3号出局，法官宣布是被刀的。2号跳预言家说验了5号是金水。4号质疑2号的警徽流不合理。"

### 2. 逻辑分析（Why）

基于信息进行推理：

- 为什么你认为某人是狼人/好人
- 逻辑链条是什么
- 有哪些矛盾或可疑点

**示例**：

> "2号的警徽流有问题：他说要验4号和6号，但4号昨天发言明显是好人，真预言家不会浪费查验。这说明2号可能是悍跳狼。"

### 3. 行动建议（How）

得出明确的结论和建议：

- 你的最终判断是什么
- 建议投票给谁
- 需要其他玩家做什么

**示例**：

> "综合判断，2号是悍跳狼的概率很高。我建议今天投2号。真预言家请跳出来对抗。"

## 决策树方法

复杂决策时，使用决策树列出所有可能的分支和结果。

**示例：女巫首夜是否用解药**

```
首夜刀口信息
├─ 刀到神职（预言家/守卫）
│  ├─ 救 → 保留神职，但后续无解药
│  └─ 不救 → 损失神职，保留解药用于关键轮次
│
├─ 刀到平民
│  ├─ 救 → 浪费解药
│  └─ 不救 → 合理，保留解药
│
└─ 空刀（无人被刀）
   ├─ 救 → 无法救（没有刀口）
   └─ 不救 → 唯一选择
```

**决策原则**：

1. 列出所有可能性
2. 评估每种选择的利弊
3. 选择期望收益最高的
4. 考虑风险和不确定性

## 视角一致性检查

**什么是视角**：
视角是指玩家在发言时，基于他声称的身份所应该知道和不知道的信息。

**视角错误**：

- 狼人知道队友身份，但好人不知道
- 预言家知道查验结果，但平民不知道
- 死人不知道死后发生的事

**如何检查视角**：

1. 假设对方说的身份是真的
2. 检查他的发言是否符合该身份应有的信息量
3. 如果出现矛盾，则可能是伪装

**示例**：

> 2号自称平民，但在分析时说"3号和5号肯定不是同阵营"。问题是，平民怎么知道3号和5号的阵营关系？这是典型的视角错误，暴露了2号可能是狼人（知道队友身份）。

## 状态与心态分析

**状态**：发言的紧张程度、流畅度、自信度

- **紧张**：可能是狼人心虚，也可能是新手好人
- **流畅**：可能是真实表达，也可能是提前准备的伪装
- **自信**：可能是真神职，也可能是悍跳狼

**心态**：发言的目的和动机

- **主动找狼**：好人心态
- **避重就轻**：可能是狼人
- **站边明确**：可能是真神职或冲锋狼
- **模棱两可**：可能是倒钩狼或摸鱼平民

## 信息分类

将信息分为三类：

### 1. 确定信息（100% 可信）

- 法官公布的死亡信息
- 你自己的角色和行动
- 你亲眼见证的事件

### 2. 高可信度信息（70-90% 可信）

- 真神职的查验结果
- 多个独立来源的一致证词
- 符合逻辑的推理结论

### 3. 不确定信息（< 70% 可信）

- 单一来源的证词
- 可能被伪装的发言
- 缺乏证据的推测

**决策原则**：

- 优先基于确定信息做决策
- 综合多个高可信度信息
- 谨慎对待不确定信息

## 常见逻辑谬误（避免）

### 1. 确认偏误

只看支持自己观点的信息，忽略相反证据。

**错误示例**：

> "我一开始就觉得3号是狼，所以他所有发言我都往狼的方向解读。"

**正确做法**：
保持开放心态，公正评估所有证据。

### 2. 锚定效应

过度依赖最初的信息，不愿意更新判断。

**错误示例**：

> "我第一天就判断3号是好人，即使后来他发言有破绽，我还是坚持这个判断。"

**正确做法**：
根据新信息及时更新判断。

### 3. 群体思维

盲目跟随多数人的观点，失去独立判断。

**错误示例**：

> "大家都说投3号，那我也投3号吧。"

**正确做法**：
理解他人的逻辑，但保持独立思考。

## 应用原则

1. **基于事实推理**：只使用已知信息，不编造未出现的事实
2. **保持逻辑一致**：前后发言不矛盾，符合你的角色设定
3. **简洁切题**：发言简短有力，避免长篇大论
4. **动态调整**：根据局势变化及时更新策略
