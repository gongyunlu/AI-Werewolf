# 预言家玩法指南

## 角色定位

预言家是好人阵营的核心神职，每晚可查验一名玩家身份（好人/狼人）。你的查验信息是好人阵营的关键情报。

## 核心策略

### 1. 查验优先级

**第一晚查验原则**：

- 优先查验发言模糊、态度暧昧的玩家
- 避免查验明显好人倾向的玩家（浪费机会）
- 记录每次查验结果，构建信息网络

**后续查验策略**：

- 查验发言矛盾、逻辑混乱的玩家
- 查验被多人指认为狼的玩家（确认身份）
- 查验关键位置（如警长候选人）

### 2. 跳神时机

**何时跳出身份**：

- 查到狼人后，在白天发言时跳出报验人
- 被狼人悍跳时，必须立即跳出对抗
- 濒死时必须跳出，公开所有查验信息

**跳神要点**：

- 清晰报出所有查验结果（日期、座位号、结果）
- 解释查验逻辑（为什么查这个人）
- 呼吁好人相信并保护你

### 3. 报验人技巧

**报好人**：

- 明确指出该玩家是好人
- 给予该玩家信任，建立好人阵线

**报狼人**：

- 清晰指认狼人座位号
- 分析该玩家的可疑行为
- 呼吁好人投票放逐

### 4. 对抗悍跳

**识别悍跳狼**：

- 对比双方查验信息的合理性
- 分析对方报验人的时机和动机
- 观察对方队友的站队行为

**对抗策略**：

- 坚定表明自己是真预言家
- 详细复盘每次查验的逻辑
- 呼吁女巫等其他神职站队

## 常见错误

- ❌ 查验明显好人，浪费机会
- ❌ 查到狼不跳，被狼人抢先悍跳
- ❌ 报验人时信息模糊，缺乏可信度
- ❌ 对抗悍跳时底气不足

## 进阶技巧

- 通过查验构建"金水链"（多个已验好人）
- 利用查验信息引导投票方向
- 与女巫、守卫等神职配合，保护关键好人
