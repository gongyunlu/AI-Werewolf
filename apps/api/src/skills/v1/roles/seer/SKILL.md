# 预言家玩法指南

## 角色定位

预言家是好人阵营的核心神职，每晚可查验一名玩家身份（好人/狼人）。你的查验信息是好人阵营的关键情报。

## 核心策略

### 1. 查验目标选择策略

#### 第一晚查验原则

**优先级排序**：

1. **发言模糊、态度暧昧的玩家**（可能是隐藏的狼人）
2. **座位边角位玩家**（经验上狼人喜欢选边角位）
3. **随机选择**（首夜信息少，盲查也合理）

**避免查验**：

- ❌ 明显好人倾向的玩家（浪费查验机会）
- ❌ 已经暴露身份的玩家（如被刀的玩家）
- ❌ 自己（浪费机会）

**首夜查验目标选择逻辑**：

```
谁最值得查？
├─ 有可疑行为的玩家 → 优先查验
├─ 发言过少或过多的玩家 → 可能隐藏身份
├─ 无明显特征 → 随机选择（边角位略优先）
└─ 明显好人 → 不查（浪费机会）
```

#### 第二晚及以后查验策略

**决策流程**：

```
查验谁？
├─ 有明确查杀目标（发言矛盾、视角错误）→ 优先查验
├─ 关键位置玩家（警长候选、发言强势）→ 确认身份
├─ 被多人指认的玩家 → 验证是否是狼
├─ 站队可疑的玩家（投票异常、保护狼人）→ 查验动机
└─ 避免查验已知身份（已验过、已被刀、已跳神）
```

**查验优先级**（由高到低）：

1. **发言矛盾、逻辑混乱的玩家**（可能是狼人伪装失败）
2. **被多人指认为狼的玩家**（确认身份，避免冤枉）
3. **关键位置玩家**（警长候选、发言强势者）
4. **票型异常的玩家**（总是保护可疑玩家）
5. **低调玩家**（可能是隐藏的狼人）

**不要查验**：

- ❌ 已验过的玩家（浪费机会）
- ❌ 明显的神职（如跳出的女巫）
- ❌ 已确认的好人（如你发的金水）

### 2. 跳神时机判断

#### 何时跳出身份

**必须跳出的情况**：

1. **查到狼人**：第一时间跳出报验人（压制狼人）
2. **被狼人悍跳**：立即跳出对抗（证明自己是真预言家）
3. **濒死时**：必须跳出，公开所有查验信息（遗言）
4. **关键决胜轮**：需要引导投票时跳出

**可以跳出的情况**：

- 查到多个好人，可以跳出建立金水链
- 局势混乱，需要预言家引导方向
- 其他神职已跳出，预言家可以配合

**不建议跳出的情况**：

- 首夜查到好人，且无狼人悍跳（保持隐藏）
- 查验信息不足，跳出无法提供价值
- 场上已有悍跳狼，等待更多信息再对抗

#### 跳神要点

**跳神话术结构**：

1. **明确身份**："我是预言家"
2. **报验人信息**：
   - 第X夜验了Y号，结果是好人/狼人
   - 按时间顺序报告所有查验
3. **解释查验逻辑**：
   - 为什么查这个人（发言可疑、位置关键）
   - 查验结果如何印证你的判断
4. **呼吁站队**：
   - 呼吁好人相信你
   - 要求女巫、守卫保护你
   - 引导投票方向

**跳神话术示例**（用你自己的风格表达）：

> "我是预言家。第一晚我验了3号，是好人。第二晚我验了5号，查杀，是狼人。我验5号是因为他昨天的发言有视角问题，他说'4号和6号肯定不是一伙的'，但平民怎么知道这个？果然验出来是狼。我建议今天投5号出局。女巫如果还有毒药，可以留给其他狼。"

### 3. 报验人技巧

#### 报好人（金水）

**报金水的价值**：

- 确认好人身份，建立可信任的阵线
- 给被验玩家背书，增加他的话语权
- 构建"金水链"（多个已验好人）

**报金水话术**：

- 明确指出该玩家是好人
- 解释为什么验他（怀疑过、位置关键）
- 给予该玩家信任，呼吁他帮助好人

**示例**：

> "我昨晚验了2号，是金水（好人）。我验他是因为他发言有点激进，担心是冲锋狼，结果是好人。2号可以站出来帮我分析局势。"

#### 报狼人（查杀）

**报查杀的要点**：

- 清晰指认狼人座位号
- 详细说明查验逻辑（为什么怀疑他）
- 分析该玩家的可疑行为（发言矛盾、票型异常）
- 呼吁好人投票放逐

**报查杀话术**：

1. **明确查杀**："X号是狼人，这是我的查杀"
2. **说明理由**："我验他是因为...（发言可疑、行为异常）"
3. **分析行为**："他昨天的发言有以下问题...（具体指出）"
4. **呼吁投票**："建议今天投X号出局"

**示例**：

> "我昨晚验了5号，查杀，是狼人。我验他是因为他昨天投票保护了3号，但3号的发言明显有问题，正常好人不会这么投。而且5号自己的发言也前后矛盾，第一天说相信我是真预言家，第二天又开始质疑我。建议今天投5号出局。"

### 4. 对抗悍跳狼

#### 识别悍跳狼

**悍跳狼的特征**：

1. **查验信息不合理**
   - 查验目标选择奇怪（查明显的好人）
   - 查验结果与实际情况矛盾

2. **报验人时机可疑**
   - 在真预言家跳出后才跳（抢位置）
   - 报验人信息过于巧合（给队友发金水）

3. **队友行为异常**
   - 有玩家无理由强力站边他（冲锋狼）
   - 票型显示有组织的保护

4. **话术不专业**
   - 缺少查验逻辑（"我就是觉得他可疑"）
   - 警徽流不合理或没有警徽流

#### 对抗策略

**对抗话术结构**：

1. **坚定表明身份**："我才是真预言家"
2. **对比查验信息**：
   - 指出对方查验的不合理之处
   - 对比你的查验逻辑更清晰
3. **分析对方动机**：
   - 对方为什么要悍跳（保护队友、混淆局势）
   - 对方的队友是谁（分析站队）
4. **呼吁站队**：
   - 呼吁女巫等神职站边你
   - 要求好人对比双方的逻辑

**对抗话术示例**：

> "2号是悍跳狼。我先跳的预言家，2号是看到我跳出来才跳的。而且他说第一晚验了4号是金水，但4号昨天的发言明显是平民视角，真预言家不会浪费机会验这种明显的好人。再看站队，5号和6号无理由强力站边2号，这很可能是冲锋狼。我呼吁好人站边我，对比我们两个的查验逻辑，谁更合理一目了然。"

#### 对抗中的关键点

**保持冷静和逻辑**：

- 不要情绪化（"他就是假的！"）
- 用逻辑和证据说话
- 详细复盘每次查验的理由

**呼吁神职配合**：

- 女巫可以毒掉悍跳狼
- 守卫可以守护真预言家
- 其他好人要对比双方逻辑

**分析站队**：

- 谁在无理由站边悍跳狼（可能是冲锋狼）
- 谁在理性分析（可能是好人）
- 根据站队推测狼坑

### 5. 警徽流（进阶技巧）

**什么是警徽流**：

预言家留下的查验计划，表明"如果我今晚被刀，明天你们要关注这些人"。

**警徽流格式**：

- "我的警徽流是：4号 → 7号"
- 意思：今晚验4号，如果我被刀，明天你们重点关注4号和7号

**警徽流的作用**：

- 被刀后留下信息（即使没来得及报验人）
- 显得专业（真预言家的标志）
- 引导好人关注方向

**警徽流选择原则**：

- 第一位：今晚要验的人
- 第二位：如果第一位已验，明晚要验的人
- 选择可疑、关键位置的玩家

## 常见错误（避免）

### 1. 查验明显好人

**错误表现**：

- 查验明显是神职的玩家（如跳出的女巫）
- 查验发言明显是好人的玩家

**后果**：

- 浪费查验机会
- 没有获得有价值的信息

**正确做法**：

- 查验可疑、模糊、关键位置的玩家
- 每次查验都要有明确目的

### 2. 查到狼不跳

**错误表现**：

- 查到狼人后，不立即跳出报验人
- 担心被悍跳，选择继续隐藏

**后果**：

- 被狼人抢先悍跳，陷入被动
- 查验信息无法及时传递给好人

**正确做法**：

- 查到狼人必须第一时间跳出
- 即使被悍跳，也要坚定对抗

### 3. 报验人信息模糊

**错误表现**：

- "我验了某个人，好像是好人"
- 不说明查验逻辑和时间

**后果**：

- 缺乏可信度
- 好人无法判断真假

**正确做法**：

- 明确报出座位号、查验时间、结果
- 详细说明查验逻辑

### 4. 对抗悍跳时底气不足

**错误表现**：

- "我可能是真预言家..."
- 被悍跳狼压制，不敢坚定表达

**后果**：

- 好人无法判断谁是真预言家
- 失去话语权

**正确做法**：

- 坚定表明身份
- 用逻辑和证据碾压悍跳狼

## 进阶技巧

### 1. 构建金水链

**什么是金水链**：
验出多个好人，形成可信任的好人阵线。

**金水链的价值**：

- 确认多个好人身份
- 好人可以互相信任，共同分析
- 压缩狼坑（剩下的人中狼概率更高）

**如何构建**：

- 连续验出好人
- 让金水玩家站出来帮你分析
- 形成"预言家 + 金水们"的好人核心

### 2. 利用查验引导投票

**查验的战略价值**：

- 不仅是获取信息，也是引导方向
- 查验关键玩家，帮助好人做决策

**应用**：

- 白天有争议的两个玩家，晚上验其中一个
- 验出结果后，引导投票方向
- 帮助好人聚焦，避免票分散

### 3. 与其他神职配合

**与女巫配合**：

- 查杀后呼吁女巫保留毒药（白天投票出局）
- 如果白天投不出去，女巫可以毒

**与守卫配合**（如果有守卫）：

- 跳出后呼吁守卫保护你
- 守卫守你时，你可以继续查验

**与好人配合**：

- 金水玩家帮你分析局势
- 好人跟随你的引导投票

### 4. 应对复杂局势

**多人跳预言家**：

- 保持冷静，坚定表明自己身份
- 对比所有人的查验逻辑
- 分析站队，找出狼坑

**被刀后的遗言**：

- 公开所有查验信息
- 说明警徽流（如果有）
- 引导好人后续投票方向

## 决策示例（参考）

### 场景 1：首夜查验谁？

**情况**：第一晚，你是预言家，需要查验一名玩家。

**决策**：

- 分析玩家位置（边角位狼人概率略高）
- 选择中间位置或随机选择
- 避免查验明显神职或明显好人

### 场景 2：查到狼人怎么办？

**情况**：第二晚，你查验了5号，结果是狼人。

**决策**：

- 第二天白天立即跳出报验人
- 清晰报出查杀信息
- 分析5号的可疑行为
- 呼吁好人投票5号

### 场景 3：被狼人悍跳怎么办？

**情况**：你跳出后，2号也跳预言家。

**决策**：

- 坚定表明自己是真预言家
- 对比双方查验信息的合理性
- 分析2号的队友（站队异常的玩家）
- 呼吁神职和好人站边你

### 场景 4：查验目标已被刀

**情况**：你计划验4号，但4号昨晚被刀了。

**决策**：

- 调整查验目标
- 选择次优目标（可疑、关键位置）
- 不要浪费查验机会

---

**重要提示**：

- 以上策略需要根据实际局势灵活调整
- 预言家的核心是**信息获取 + 引导方向**
- 查验要有目的，报验人要清晰，对抗要坚定
