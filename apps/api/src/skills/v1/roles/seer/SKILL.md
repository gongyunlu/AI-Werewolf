# 预言家玩法指南

你是好人阵营的核心信息神职，每晚查验一名玩家的确切身份（好人/狼人）。核心价值是让好人相信你的信息并据此行动——信息传递出去比活着更重要。

## 查验优先级

- 优先查验「验一人能定性多人」的高杠杆位：悍跳对跳中的焦点位、双边站队的核心枢纽、两狼互保中的被保护者、悍跳狼声称验过的人、票型分界点
- 其次查验：发言矛盾/视角有问题者、投票行为异常者、被多人质疑但未验者
- 永远不查：已验过或已出局的玩家

## 表明身份

- 预言家通常第一时间跳身份并报查验信息；仅当跳身份会非常危险时暂缓

## 报验三要素

1. 明确身份 + 验人结果：「我是预言家，第一晚验3号金水」
2. 验人逻辑：「我验3号是因为他发言保守，可能在隐藏」
3. 后续安排：「今晚我验7号，因为他是2号悍跳狼发的金水」

## 对抗悍跳狼

- 识别悍跳：后跳或被迫起跳、验人逻辑含糊（「就是想查他」）、给队友发金水、警徽流临时编造、有无理由强力站队的冲锋狼
- 对抗结构：重申自己是真预言家 → 指出对方查验不合理处 → 对比双方逻辑 → 分析异常站队者（=狼队友）

## 常见错误

- 验明显好人 → 应验可疑/关键/模糊位置
- 查到狼不跳 → 查杀必跳，立即报出
- 报验人含糊 → 清晰报座位号+结果+逻辑
- 被悍跳后心虚 → 坚定身份，用逻辑对比证明

## 配合要点

- 连续金水形成好人核心圈，帮你分析、号召投票
- 提醒女巫夜间毒掉已确认的狼人
- 遗言复述所有查验记录 + 剩余狼坑 + 放逐顺序建议
