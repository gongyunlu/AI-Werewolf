# 预言家玩法指南

## 角色定位

预言家是好人阵营的**核心信息神职**，每晚可查验一名玩家的确切身份（好人/狼人）。核心价值在于**让好人相信你的信息并据此行动**。

> 心法：预言家的命不重要，**信息传递出去**才重要。哪怕第一天被放逐，只要验人信息被好人采信，任务就完成了。

## 一、查验策略

### 1.1 首夜查验原则

| 优先级 | 目标类型                             | 理由               |
| :----: | :----------------------------------- | :----------------- |
|   1    | 发言暧昧、态度模糊的玩家             | 狼人首夜易发言保守 |
|   2    | 边角位玩家（如12人局中的1/6/7/12号） | 纯数据位置概率学   |
|   3    | 随机选择                             | 首夜盲查合理       |

### 1.2 查验的杠杆效应（核心原则）

**原则**：优先查验"验一人能定性多人"的玩家——信息回报率最高。

| 场景                     | 验出后的连锁效应                                                       |
| :----------------------- | :--------------------------------------------------------------------- |
| **悍跳对跳中的焦点位**   | 查杀→坐实对方是悍跳狼，站边其者进狼坑；金水→其阵营可能是被蒙蔽的好人   |
| **双边站队的核心枢纽**   | 金水→获得强力帮手；查杀→瓦解对方核心，追随者全部可疑                   |
| **两狼互保中的被保护者** | 查杀→保护者大概率是狼队友；金水→保护行为合理                           |
| **两人穿同一神职衣服**   | 查A金水→B大概率是穿衣服的狼；查A查杀→A是狼，B需重新评估                |
| **悍跳狼声称验过的人**   | 查杀（狼踩狼/狼保狼）→双狼捆绑；金水→悍跳狼在拉拢好人票                |
| **悍跳狼的核心票仓**     | 查杀→冲锋狼坐实悍跳，其余票仓进狼坑（狼队绑票）；金水→该票仓可能被蒙蔽 |
| **票型分界点**           | 查其身份可判断胜负手一侧的阵营属性                                     |

> 一句话：查验不只看目标本人是否可疑，更要看"验出他后能看懂多少人的身份"。

### 1.3 后续查验优先级

按优先级从高到低：

1. **高杠杆效应玩家**（见1.2）
2. **发言矛盾、视角有问题者**——最易暴露狼人视角
3. **投票行为异常者**——如连续保护可疑对象
4. **被多人质疑但未验者**——避免冤枉或被带节奏
5. **站队过于坚定者（无论站谁）**——极端站队常有狼人动机
6. **存在感过低、发言稀少者**——深水狼常用策略

**永远不查**：已验过或已出局的玩家。

## 二、表明身份时机

**预言家通常第一时间表面自己身份，并报出自己的查验信息**
仅当认为现在表明身份会非常危险时可以选择暂时不表面身份。

## 三、报验人技巧

### 3.1 发言三要素

每次跳预言家必须包含：

1. **明确身份 + 验人结果**
   比如："我是预言家，第一晚验3号金水。"
2. **验人逻辑**
   比如："我验3号是因为他发言保守，可能在隐藏。"
3. **后续安排**
   比如："今晚我会验7号，7号是2号悍跳狼发的金水，我需要知道7号是不是2号的狼队友，在玩狼保狼的战术。"

### 3.2 警徽流（如果当前规则有警长）

**定义**：提前公布未来两晚的验人规划和原因，如"今晚验4号，明晚验7号"。

**作用**：被刀后通过警徽传递验人结果——金水传警徽给该玩家，查杀传给明确好人或撕警徽。

> 拿到警长后，被刀**须要通过警徽传递信息**，否则验人作废。比如：白天说要验4号
>
> 1. 查验结果是好人，把警徽给4号；
> 2. 查验结果是狼人，把警徽给之前查验的且当前存活的好人。如果没有，则可以选择给你当前最认可的好人或者撕掉警徽。

## 四、对抗悍跳狼

### 4.1 识别悍跳狼

| 维度     | 真预言家特征   | 悍跳狼可疑特征           |
| :------- | :------------- | :----------------------- |
| 跳的时机 | 先跳           | 后跳或被迫起跳           |
| 验人逻辑 | 每次有明确理由 | "就是想查他"             |
| 验人目标 | 可疑、关键位置 | 验明好人或给队友发金水   |
| 警徽流   | 清晰有规划     | 没有或临时编造           |
| 队友行为 | 金水理性分析   | 有无理由强力站队的冲锋狼 |

### 4.2 对抗结构

1. 重申自己是真预言家
2. 指出对方查验的不合理之处
3. 对比双方逻辑
4. 分析站队玩家（异常站队=狼队友）

## 五、常见错误

| 错误         | 正确做法                     |
| :----------- | :--------------------------- |
| 验明显好人   | 验可疑、关键、模糊位置的玩家 |
| 查到狼不跳   | 查杀必跳，立即报出           |
| 报验人含糊   | 清晰报座位号+结果+逻辑       |
| 被悍跳后心虚 | 坚定身份，用逻辑对比证明     |
| 不敢出查杀   | 查杀就是铁证，坚决要求放逐   |

## 六、配合要点

- **金水链**：连续验出金水形成好人核心圈，金水帮你分析、号召投票
- **女巫**：提醒女巫夜间用毒毒已确认的狼人
- **遗言**：复述所有查验记录 + 剩余狼坑 + 放逐顺序建议

**最终心法**：预言家的本质不是"活着验人"，而是"让验人信息在死后依然发挥作用"。清晰、坚定、逻辑连贯——做到这三点，即使第一天倒牌，也是好人的胜利基石。
