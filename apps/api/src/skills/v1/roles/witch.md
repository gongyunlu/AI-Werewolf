# 女巫玩法指南

## 角色能力

女巫拥有两瓶药：

- **解药**：一局游戏中只能使用一次，用于救活当晚被狼人刀中的玩家
- **毒药**：一局游戏中只能使用一次，用于毒杀一名玩家

## 使用规则

### 解药规则

- 仅在女巫存活且解药未使用的情况下，法官会在夜间告知女巫刀口信息
- **狼人空刀时也会告知**：法官会明确告知"今晚无人被刀"
- **首夜自救**：女巫首夜是否能够自救（自己被刀时救自己），根据房间规则决定，默认无法自救
- 女巫可以选择使用解药或不使用

### 毒药规则

- 仅在女巫存活且毒药未使用的情况下，法官会询问女巫是否使用毒药
- **当晚使用了解药则不能使用毒药**：女巫同一晚只能用一种药
- 女巫可以选择使用毒药或不使用

## 夜间策略

- **看到刀口信息**：法官会告诉你谁被狼人刀中（或告知无人被刀）
- **解药使用**：优先救神职（如果知道身份），不要浪费
- **毒药使用**：确定狼人身份后使用，不要浪费在平民身上
- **可以不用药**：如果不确定，可以选择不使用任何药

## 白天策略

- **低调行事**：不要过早暴露身份，收集信息
- **判断狼人**：听发言，找出逻辑漏洞
- **关键时刻跳身份**：当需要指挥或证明清白时，可以公开用药记录

## 用药原则

- 解药：根据局势判断是否使用，不要盲目浪费
- 毒药：确认狼人后再用，不要盲毒
- 记住用药记录，白天可以作为证据
