# 村民玩法指南

## 角色定位

村民是好人阵营的基础角色，没有夜间技能，但可以通过白天发言和投票影响局势。虽然没有特殊能力，但村民的逻辑推理和投票选择对胜负至关重要。

## 核心策略

### 1. 信息收集

**倾听与观察**：

- 仔细倾听每个玩家的发言
- 记录关键信息（跳神、查验结果、站队）
- 观察玩家之间的互动和站队关系

**判断神职**：

- 识别跳出的预言家、女巫等神职
- 判断真假预言家（对比查验信息）
- 相信可信度高的神职

### 2. 发言策略

**表达立场**：

- 清晰表达你对局势的判断
- 说明你的投票意向和理由
- 不要保持沉默（容易被认为是狼人）

**逻辑推理**：

- 基于已知信息进行推理
- 指出可疑玩家的矛盾之处
- 避免无根据的指认（容易误导好人）

**避免暴露弱点**：

- 不要说"我是村民"（狼人也会这么说）
- 用逻辑和推理证明你是好人
- 积极参与讨论，展现好人思维

### 3. 投票判断

**投票原则**：

- 跟随可信神职的指引（如真预言家）
- 投给发言矛盾、逻辑混乱的玩家
- 投给多数好人认同的可疑对象

**独立思考**：

- 不盲目跟票
- 如果发现投票对象可能是好人，及时改票
- 关键时刻的投票可能决定胜负

### 4. 站队选择

**预言家对跳**：

- 仔细对比双方的查验信息
- 分析双方的逻辑和可信度
- 站队后坚定支持，不轻易摇摆

**关键选择**：

- 在悍跳局中，站对边很重要
- 观察其他玩家的站队（可能暴露狼队）
- 与其他好人形成统一战线

## 常见错误

- ❌ 保持沉默，不参与讨论
- ❌ 盲目跟票，没有独立判断
- ❌ 无根据地指认好人，制造混乱
- ❌ 轻易改变站队，造成好人分裂

## 进阶技巧

- 通过发言引导好人达成共识
- 识别狼人的发言套路（煽动、带节奏）
- 关键时刻主动发言，稳定局势
- 与神职配合，形成好人优势
