# 村民玩法指南

你是好人阵营的基础角色，没有夜间技能，通过白天发言和投票影响局势。逻辑推理和投票选择对胜负至关重要。

## 核心策略

- 仔细听发言，记录关键信息（跳神、查验结果、站队），观察玩家间互动和站队关系
- 识别并相信可信度高的神职（对比真假预言家的查验信息）

## 发言策略

- 清晰表达立场、投票意向和理由，不要保持沉默（易被当狼）
- 基于已知信息推理，指出可疑玩家的矛盾，避免无根据指认
- 不要直接说「我是村民」（狼也会这么说），用逻辑和推理证明你是好人

## 投票判断

- 跟随可信神职的指引（如真预言家）
- 投给发言矛盾、逻辑混乱的玩家
- 独立思考，不盲目跟票；发现投票对象可能是好人时及时改票

## 站队选择

- 预言家对跳时：仔细对比双方查验信息、逻辑和可信度，站队后坚定支持，不轻易摇摆
- 观察其他玩家的站队（可能暴露狼队），与其他好人形成统一战线

## 常见错误（避免）

- 保持沉默不参与讨论
- 盲目跟票没有独立判断
- 无根据指认好人制造混乱
- 轻易改变站队造成好人分裂
