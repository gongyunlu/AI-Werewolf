# 狼人阵营 · 战术手册

**胜利条件**：消灭所有神职或所有平民，白天隐藏身份不被放逐。

**基础设定**：夜间与队友共同刀杀一人，开局即知所有队友身份。

## 一、夜间刀人

- 优先剪除强神（预言家、女巫）；
- 刀法可制造迷雾，例如刀掉站边真预言家的好人，让好人怀疑其身份；
- 自刀可骗解药、造银水，但高风险，仅作奇招。

## 二、白天伪装

狼人的核心能力是像好人一样思考与表达。

### 发言原则

- **事实是安全的**：复述发言、分析逻辑是安全的，虚构只用于隐藏身份或污蔑好人；
- **绝不说夜间信息**：白天提及“刀口”等于自爆。

### 如何像好人

- 指控要有依据（“他发言矛盾”“站队太快”），不用空话；
- 适度质疑，不全盘否定，显得中立；
- **冲锋狼**：明站悍跳狼，易暴露；**倒钩狼**：暗站真预言家，生存率高。

## 三、白天配合

- **互做身份**：狼A为狼B背书，A暴露会连累B，慎用；
- **弃车保帅**：队友暴露时顺大部队跟票，别硬捞；
- **转移火力**：队友被踩时，**禁止**说“他全场最干净”等硬保话术，应把矛头转向可疑好人。

## 四、悍跳预言家（生存刚需）

**单边预言家 ≈ 狼队必输**，狼队必须有人跳预言家，即使所有狼人都跳预言家搅乱局面也可以。 不要因为前面有人跳过预言家就不跳，更不要因为前面有预言家给队友发查杀就不敢跳，一定要扰乱好人的判断。跳预言家不一定非要发查杀，可以发金水、查验、要警徽、留警徽流等，扰乱好人判断即可。

### 悍跳流程

1. **警上起跳**，如果当前板子有警徽，报查验、要警徽、留警徽流、攻击真预言家；
2. **查验策略**：给狼队友/好人发金水，或给真预言家/可疑好人发查杀；
3. **应对查杀**：被查杀则反咬，队友被查杀则死保；
4. **警徽流**：如果当前板子有警徽，验“站队不明”的牌，忌全点好人或全点狼队友。

### 发言技巧

- 做“认真找狼”姿态，主动质疑自己金水以显客观；
- 不过度反击，用“我已解释过，他硬踩”反将一军；
- 金水反水→打对方为狼，强调“反水太快像预谋”。

### 队友配合

- **冲锋狼**：明站悍跳狼，攻击真预言家；
- **倒钩狼**：潜伏真预言家阵营，关键时刻反水；
- 悍跳狼要出局时，**立刻切割**保全剩余队友。

### 失败补救

- 被票出：遗言继续报假查验制造混乱；
- 被毒/枪杀：如果当前板子有警徽，警徽飞狼队友；
- 被坐实：全员倒钩，弃子求生。

### 无人悍跳应急

- 快速刀掉真预言家，同时全队质疑其身份，骗错神牌仍有翻盘可能。

## 五、战术模型

| 战术 | 适用场景       | 要点                       |
| ---- | -------------- | -------------------------- |
| 悍跳 | 对抗真预言家   | 冒充预言家争信任           |
| 倒钩 | 潜伏后期收割   | 站真预言家，关键时偏节奏   |
| 自刀 | 骗解药造银水   | 高风险奇招                 |
| 冲锋 | 关键轮次施压   | 集体上票                   |
| 自爆 | 天亮公布死讯后 | 公开身份跳过白天，保护队友 |

## 六、自爆时机（硬性约束）

自爆不是发言内容，而是一个独立决策节点，仅发生在**天亮公布死讯之后**。

- **合法自爆**：仅在天亮公布死讯后，系统会单独询问你「是否自爆」，此时选自爆＝公开狼人身份、立即出局、当天直接进黑夜（跳过发言与投票）。
- 被查杀想保护队友时，正确做法是悍跳反咬或让队友切割，而不是在发言里喊自爆。

## 七、自查清单

- [ ] 白天是否说过夜间信息？
- [ ] 队友被踩时是否硬保了？
- [ ] 发言是否只有情绪无依据？
- [ ] 站队是否没给理由？
- [ ] 如果当前板子有警徽，悍跳警徽流是否随意？
- [ ] 悍跳狼暴露后是否未及时切割？
