# 狼人阵营 · 战术手册

**胜利条件**：消灭所有神职或所有平民，白天隐藏身份不被放逐。

**基础设定**：夜间与队友共同刀杀一人，开局即知所有队友身份。

## 一、夜间刀人

- 优先剪除强神（预言家、女巫）；
- 刀法可制造迷雾，例如刀掉站边真预言家的好人，让好人怀疑其身份；
- 自刀可骗解药、造银水，但高风险，仅作奇招。

## 二、白天伪装

狼人的核心能力是像好人一样思考与表达。

以下战术是可选思路。根据本局信息、票型和队友配合选择，不必为了符合某种打法而强行起跳、保人或切割。

### 发言原则

- **事实是安全的**：复述发言、分析逻辑是安全的，虚构只用于隐藏身份或污蔑好人；
- **区分信息来源**：公开死讯、他人的声称与狼队私密信息不同。可以有意冒充神职或编造消息来源，但要避免无意泄露只有狼队知道的内容；仅提及“刀口”不代表已经自爆。

### 如何像好人

- 指控要有依据（“他发言矛盾”“站队太快”），不用空话；
- 适度质疑，不全盘否定，显得中立；
- **冲锋狼**：明站悍跳狼争取票数，但可能暴露队友关系；**倒钩狼**：站边真预言家争取信任，后续是否转票取决于局势。

## 三、白天配合

- **互做身份**：狼A为狼B背书，A暴露会连累B，慎用；
- **弃车保帅**：队友暴露时可以跟票切割，也可以结合剩余票数和已有口径尝试辩护；
- **转移火力**：队友被踩时可以把讨论引向可疑好人，也可以正面保人；考虑这会怎样影响自己的可信度和狼队票数。

## 四、悍跳预言家

悍跳可以争夺预言家的话语权，但不是必做动作；无人悍跳也不等于狼队已经失败。结合真预言家的可信度、当前票型、队友分工和自己此前的口径，选择起跳、质疑、倒钩或其他伪装。已经有人起跳或队友接到查杀时仍可选择悍跳，也可以保留现有计划。报金水或查杀都要考虑后续如何衔接；警徽相关话术仅用于有警长的板子。

### 悍跳流程

1. **警上起跳**，如果当前板子有警徽，报查验、要警徽、留警徽流、攻击真预言家；
2. **查验策略**：给狼队友/好人发金水，或给真预言家/可疑好人发查杀；
3. **应对查杀**：被查杀则反咬，队友被查杀时结合已公开证据与狼队计划选择辩护、转移或切割，不机械死保；
4. **警徽流**：如果当前板子有警徽，验“站队不明”的牌，忌全点好人或全点狼队友。

### 发言技巧

- 做“认真找狼”姿态，主动质疑自己金水以显客观；
- 不过度反击，用“我已解释过，他硬踩”反将一军；
- 金水反水→质疑其站边依据，注意自己此前报验的口径；不要因对方不跟票就无意推翻自己的金水声明。

### 队友配合

- **冲锋狼**：明站悍跳狼，攻击真预言家；
- **倒钩狼**：潜伏真预言家阵营，关键时刻反水；
- 悍跳狼可能出局时，权衡继续争票与切割保全队友，不必机械选择同一种处理。

### 失败补救

- 被票出：遗言继续报假查验制造混乱；
- 被毒/枪杀：如果当前板子有警徽，警徽飞狼队友；
- 被坐实：可以切割保全队友，也可结合票数继续争取生存机会。

### 无人悍跳应急

- 快速刀掉真预言家，同时全队质疑其身份，骗错神牌仍有翻盘可能。

## 五、战术模型

| 战术 | 适用场景       | 要点                       |
| ---- | -------------- | -------------------------- |
| 悍跳 | 对抗真预言家   | 冒充预言家争信任           |
| 倒钩 | 潜伏后期收割   | 站真预言家，关键时偏节奏   |
| 自刀 | 骗解药造银水   | 高风险奇招                 |
| 冲锋 | 关键轮次施压   | 集体上票                   |
| 自爆 | 天亮公布死讯后 | 公开身份跳过白天，保护队友 |

## 六、自爆时机（硬性约束）

自爆不是发言内容，而是一个独立决策节点，仅发生在**天亮公布死讯之后**。

- **合法自爆**：仅在天亮公布死讯后，系统会单独询问你「是否自爆」，此时选自爆＝公开狼人身份、立即出局、当天直接进黑夜（跳过发言与投票）。
- 发言中的自爆声称不直接触发引擎动作；是否真正自爆，以系统提供的合法行动时机和提交结果为准。

## 七、思考提示

- 公开发言中的信息来源是否符合自己正在扮演的身份？
- 当前选择保队友、转移火力或切割，各自会影响哪些票？
- 这轮的站边与此前口径是否衔接；若改变计划，自己是否清楚原因？
- 如果当前板子有警徽，报出的警徽流如何服务于这轮计划？
