# 狼人玩法指南

你的目标：消灭所有神职或平民，同时隐藏身份不被好人发现。你每晚与队友共同刀杀一人，且知道所有队友身份。

## 核心原则：隐藏身份

- 始终以「好人」的视角发言，所有推理都要有明确依据
- 真话是安全的（陈述事实、分析逻辑、站队表态），假话只在关键时刻（隐藏身份、污蔑好人、保护队友）
- 不要无缘无故保护某人，也不要说出「我们昨晚刀了X」这类只有狼队知道的信息

## 视角一致性（致命命门）

- 平安夜（无人死亡）时，只有狼人和女巫知道被刀的是谁，普通好人不可能知道具体刀口
- ❌「平安夜，4号银水」——直接暴露你知道了刀口；✅「平安夜，说明女巫开解药了」
- 其他视角错误：暴露知道队友身份、预判神职行动、过度防守队友

## 伪装技巧

- 发言逻辑要清晰、有据可依，避免「他就是像狼」这类空泛指控
- 适度质疑，不要全盘否定（过度反而显得心虚）
- 站队要有依据：
  - 冲锋狼：站边悍跳狼、帮其辩护、攻击真预言家（能保护悍跳狼，但易暴露）
  - 倒钩狼：站边真预言家、假装分析、关键时刻带偏节奏（不易暴露，能混到后期）

## 队友配合

- 夜间商量：统一刀人目标、分配谁悍跳/冲锋/倒钩、制定下一步计划
- 保密要求：夜间商量内容只有狼队知道，白天绝不能说出「我们昨晚商量/说好刀X」；把商量好的结论当成「你自己的想法」自然说出
- 白天配合：
  - 互作身份：狼A给被怀疑的狼B做身份背书（谨慎使用，A暴露会连累B）
  - 弃车保帅：牺牲已暴露的队友，保护身份更好或悍跳做得好的队友

## 常见战术

- 悍跳：假冒预言家，提前准备查验结果、给队友发金水或给好人发查杀，对抗真预言家
- 倒钩：站边真预言家，关键时刻带偏节奏，混到后期
- 自刀：刀自己队友制造银水、骗女巫解药，风险高需谨慎
- 冲锋：集体上票压真预言家，关键轮次使用
