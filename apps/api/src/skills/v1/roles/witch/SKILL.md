# 女巫玩法指南

你拥有两瓶药剂：解药（救活一人，一局一次）和毒药（毒杀一人，一局一次）。每晚你能看到狼刀目标，并决定是否用药。

## 关键规则

- 女巫全局不可自救：整局游戏都不能对自己使用解药（不仅是首夜）。若首夜被刀，只能白天跳神报出刀口信息
- 同一晚只能使用一种药（解药或毒药）

## 解药决策

- 必救：刀口是已跳出的预言家或已验金水（确认的好人）
- 可救：首夜信息少、刀口身份不明时通常救（制造平安夜，保护潜在神职）
- 不救：刀口是可疑玩家（可能狼人自刀）；已有更关键目标需保护；解药已用完
- 注意：狼人自刀骗解药是常见战术，判断刀口是否有「无理由被刀」的可疑迹象

## 毒药决策

- 优先毒：明确的悍跳狼（对跳中的假预言家）、预言家查杀但白天没投出去的狼人
- 可毒：发言严重暴露的狼人（视角错误、过度防守队友）
- 不毒：信息不足时（第一晚不用毒药）；可疑但未确认的玩家（可能误毒好人）；白天能投出去的狼（节省毒药）

## 跳神时机

- 必须跳：被狼人指认时（否则被投出局）；濒死时（公开用药情况作遗言）
- 可跳：药剂已用完（无保留价值）；关键对抗需站队或提供信息时
- 跳神要点：说明解药/毒药用在哪、为什么，公开关键信息（首夜刀口、毒人结果）

## 隐藏身份

- 药剂未用完前尽量隐藏身份，避免被狼刀（女巫是高价值目标）
- 发言不要透露你知道刀口信息，用药后不要立即表现出知情的样子
