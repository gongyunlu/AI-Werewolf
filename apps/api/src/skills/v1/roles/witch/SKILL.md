# 女巫玩法指南

## 角色定位

女巫拥有两瓶药剂：解药（救人一次）和毒药（毒杀一次）。你每晚可以看到狼刀目标，并决定是否使用药剂。

## 核心策略

### 1. 解药使用决策树

#### 重要规则：女巫不可自救

**官方规则明确**：女巫在整局游戏中都**不能对自己使用解药**（不仅是首夜）。

因此，如果你首夜被刀：

- **无法自救**：你只能选择不使用解药，等待天亮后跳出身份公布信息
- **战略价值**：即使被首刀也要在白天跳出，报出刀口信息和毒药威慑

#### 第一晚救人决策（刀口不是你自己）

**决策流程**：

```
是否使用解药？
├─ 刀口是已跳出的预言家 → 必救（保护核心神职）
├─ 刀口是已验好人（金水） → 优先救（已确认身份）
├─ 刀口是可疑玩家 → 不救（可能是狼人自刀）
├─ 刀口是你自己 → 无法救（规则禁止自救）
├─ 刀口是普通平民 → 视情况
│   ├─ 解药已用 → 无法救
│   ├─ 预期后续有更关键目标 → 不救
│   └─ 无特殊情况 → 可救
└─ 平安夜（无刀口） → 解药无效
```

**何时不救**：

- 刀口玩家发言可疑，可能是狼人自刀
- 已有其他神职跳出，需要保护更重要的目标
- 刀口玩家是普通平民，且你预期后续有更关键时机
- 解药已用完

### 2. 毒药使用决策树

#### 使用时机判断

**决策流程**：

```
是否使用毒药？
├─ 有明确查杀（预言家验出的狼） → 可毒（但优先白天投票）
├─ 有明显悍跳狼 → 可毒（对抗假预言家）
├─ 有发言暴露的狼人 → 可毒（视角错误、逻辑矛盾）
├─ 关键回合需要额外击杀 → 可毒（加速进程）
└─ 信息不足 → 不毒（避免误毒好人）
```

**毒人优先级**（由高到低）：

1. **明确的悍跳狼**（预言家对跳中的假预言家）
2. **查杀确认的狼人**（但优先白天投票出局）
3. **发言严重暴露的狼人**（视角错误、过度防守队友）
4. **关键轮次的可疑玩家**（票型异常、逻辑混乱）

**何时不毒**：

- **第一晚不建议使用**（信息不足，容错率低）
- **不毒可疑但未确认的玩家**（可能误毒好人）
- **白天能投出去的狼人**（节省毒药）
- **留毒药给关键回合**（最后一晚、关键决胜局）

**慎用毒药的场景**：

- 只有一个人指认某人是狼（缺乏佐证）
- 对方有合理的辩解（可能是误会）
- 场上有多个可疑目标（不确定谁最该毒）

### 3. 跳神时机

**何时跳出**：

- **被狼人指认时**：必须跳出自证（否则可能被投出局）
- **药剂已全部用完**：可跳出提供信息（无保留价值）
- **濒死时**：必须跳出，公开用药情况（遗言）
- **关键对抗时**：需要站队或提供关键信息

**跳神要点**：

- 说明解药、毒药的使用情况（用在谁身上，为什么）
- 解释每次用药的逻辑（证明决策合理性）
- 给好人提供关键信息（如第一晚刀口、毒人结果）
- 呼吁好人保护你或相信你的判断

**跳神话术示例**（用你自己的风格表达）：

> "我是女巫。第一晚刀的是3号，我用解药救了。第二晚刀的是5号，我判断5号可能是自刀，所以没救。毒药还在手，我打算今晚毒掉悍跳的2号。"

### 4. 隐藏身份策略

**不轻易跳神**：

- 药剂未用完前，尽量隐藏身份
- 避免被狼人针对（女巫是高价值目标）
- 留药剂在关键时刻发挥作用

**隐藏技巧**：

- 发言时不要透露你知道刀口信息
- 不要过度关注某个被刀的玩家
- 用药后不要立即表现出知情的样子

### 5. 平安夜制造

**什么是平安夜**：
晚上无人死亡（狼人刀人被女巫救，且女巫不用毒药）。

**制造平安夜的意义**：

- 迷惑狼人（不知道为什么没死人）
- 保护解药信息（狼人不知道女巫救了谁）
- 节省毒药（关键时刻再用）

**何时制造平安夜**：

- 刀口是普通平民，值得救
- 不想暴露女巫身份
- 希望迷惑狼人的刀人策略

## 常见错误（避免）

### 1. 首夜盲目自救（已修正：女巫不能自救）

**错误理解**：

- ~~认为女巫首夜可以自救~~

**正确规则**：

- **女巫全局不能自救**（官方规则明确禁止）
- 如果首夜被刀，无法使用解药救自己
- 唯一选择：等待天亮后跳出身份，公布信息

**如果首夜被刀怎么办**：

- 不要使用解药（因为救不了自己）
- 白天第一时间跳出女巫身份
- 公布毒药还在，威慑狼人
- 提醒好人首夜刀口是你（女巫），狼队刀法精准

### 2. 毒药乱用

**错误表现**：

- 信息不足时轻易使用毒药
- 凭直觉毒人，缺乏逻辑依据

**后果**：

- 误毒好人，帮助狼队
- 浪费关键技能

**正确做法**：

- 有明确依据再毒（查杀、悍跳、视角错误）
- 优先白天投票，毒药留给关键时刻

### 3. 药剂在手就跳神

**错误表现**：

- 解药或毒药还在，为了站队或表态就跳神

**后果**：

- 暴露身份，成为狼人刀人目标
- 药剂被浪费（被刀后无法使用）

**正确做法**：

- 药剂未用完前，尽量隐藏身份
- 只在必要时跳神（被指认、濒死、关键对抗）

### 4. 盲目救人

**错误表现**：

- 不分析刀口玩家的价值，见刀口就救
- 不考虑可能是狼人自刀

**后果**：

- 救了狼人自刀，帮助狼队制造银水
- 浪费解药，后续无法救关键目标

**正确做法**：

- 分析刀口玩家的身份（神职、平民、可疑玩家）
- 判断是否可能是自刀（发言可疑、无理由被刀）
- 有依据再救，不确定时可以不救

## 进阶技巧

### 1. 通过不救制造信息

- 不救刀口，制造"平安夜"迷惑狼人
- 观察刀口规律，判断狼人策略（优先刀神职还是刀平民）
- 根据刀口选择，推测狼人的意图

### 2. 与预言家配合

- 预言家查杀的狼人，可以毒掉（加速进程）
- 预言家跳出后，优先保护预言家（解药留给他）
- 预言家濒死时，考虑毒掉悍跳狼（对抗假预言家）

### 3. 利用药剂威慑力

- 即使药剂已用完，也可以用"我还有毒药"威慑狼人
- 跳神时不要立即公开药剂已用完（保留威慑力）
- 关键时刻再公开药剂情况（提供完整信息）

### 4. 毒药 timing 控制

- 不要在第一晚使用毒药（信息不足）
- 优先在白天投票无法出局的狼人（白天投平民，晚上毒狼）
- 最后一晚如果毒药还在，必须使用（否则浪费）

## 决策示例（参考）

### 场景 1：首夜被刀

**情况**：你是女巫，首夜看到刀口是你自己。

**决策**：

- **无法自救**（官方规则禁止女巫自救）
- 等待天亮后第一时间跳出身份
- 公布"我是女巫，首夜被刀，毒药还在"
- 威慑狼人，让好人知道神职受损情况

### 场景 2：第一夜刀口是其他玩家

**情况**：首夜刀口是3号玩家（你不知道他的身份）。

**决策**：

- **建议救**（首夜信息少，3号可能是神职）
- 制造平安夜，保护潜在神职
- 白天观察3号的发言和身份
- 如果3号是自刀狼，后续可以根据他的表现识破

### 场景 3：第二夜刀口是跳出的预言家

**情况**：白天有玩家跳预言家，晚上他被刀。

**决策**：

- 必救（预言家是好人阵营核心）
- 制造平安夜（保护预言家）

### 场景 3：白天有明确查杀

**情况**：预言家查杀了3号，白天3号可能被投出局。

**决策**：

- 优先白天投票出局（节省毒药）
- 如果3号没被投出局，晚上可以毒掉

### 场景 4：怀疑某人是悍跳狼

**情况**：2号自称预言家，但你觉得他是悍跳狼。

**决策**：

- 如果有明确证据（查杀矛盾、逻辑错误）→ 可毒
- 如果只是怀疑 → 不毒（等白天投票或更多信息）

---

**重要提示**：

- 以上策略需要根据实际局势灵活调整
- 女巫的核心是**信息利用 + 关键时刻的决策**
- 用药要有依据，不要凭直觉
