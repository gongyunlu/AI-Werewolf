# 女巫玩法指南

## 角色定位

女巫拥有两瓶药剂：解药（救人一次）和毒药（毒杀一次）。你每晚可以看到狼刀目标，并决定是否使用药剂。

## 核心策略

### 1. 解药使用原则

**第一晚是否自救**：

- **建议自救**：保留解药给后期关键神职（如跳出的预言家）
- **不自救情况**：确认刀口是平民，保留解药救预言家等关键位置

**后续解药使用**：

- 优先救跳出的预言家
- 救被确认的好人（如金水）
- 不救可疑玩家（可能是狼人自刀）

**何时不救**：

- 刀口玩家发言可疑，可能是狼人自刀
- 已有其他神职跳出，需要保护更重要的目标
- 解药已用完

### 2. 毒药使用策略

**使用时机**：

- 确认悍跳狼身份后，直接毒杀
- 白天发言暴露身份的狼人
- 关键时刻（如平安夜后）毒掉可疑玩家

**慎用毒药**：

- 第一晚不建议轻易使用（信息不足）
- 不毒可疑但未确认的玩家（可能误毒好人）
- 留毒药给关键回合

### 3. 跳神时机

**何时跳出**：

- 被狼人指认时，必须跳出自证
- 药剂已全部用完，可跳出提供信息
- 濒死时必须跳出，公开用药情况

**跳神要点**：

- 说明解药、毒药的使用情况
- 解释每次用药的逻辑
- 给好人提供关键信息（如第一晚刀口）

### 4. 隐藏身份

**不轻易跳神**：

- 药剂未用完前，尽量隐藏身份
- 避免被狼人针对
- 留药剂在关键时刻发挥作用

## 常见错误

- ❌ 第一晚盲目自救，浪费解药
- ❌ 毒药乱用，误毒好人
- ❌ 药剂还在手就跳神，暴露身份
- ❌ 不救明确的好人（如预言家）

## 进阶技巧

- 通过不救刀口，制造"平安夜"迷惑狼人
- 观察刀口规律，判断狼人策略
- 与预言家配合，毒掉确认的狼人
- 利用药剂威慑力，影响狼人刀人决策
