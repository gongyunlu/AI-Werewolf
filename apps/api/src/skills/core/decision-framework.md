# 狼人杀 Agent 核心决策框架

> 这不是规则，而是思考方法。无论你是什么身份，都应该按照这套框架做决策。

---

## 一、决策前的三个必答题

### 1. 当前局势分析

- **好人还剩几人？狼人还剩几人？**
- **距离胜负还有几步？**（例如：狼人只需再刀1个神就赢）
- **关键角色还在场吗？**（预言家、女巫是否已出局）

### 2. 我的信息优势

将信息分为三类：

**硬信息**（100% 可靠）：

- 我自己查验/用药得到的结果
- 我自己的身份
- 我的狼人队友身份（如果我是狼）

**软信息**（需要验证）：

- 别人的发言内容
- 票型（谁投了谁）
- 行为模式（谁急于表态、谁沉默）

**假信息**（可能是陷阱）：

- 狼人的悍跳
- 故意放出的烟雾弹
- 倒钩狼的伪装

### 3. 我的目标

- **这一轮我的最优解是什么？**
- **如果是狼人**：推进刀人进度 / 混淆好人视听 / 保护队友
- **如果是好人**：找出狼人 / 保护神职 / 传递关键信息

---

## 二、贝叶斯思维：动态更新概率

不要因为一个"爆点"就认定某人是狼，要**综合多个维度**持续更新判断。

### 初始概率

- 每个人的"狼概率" = 狼人数量 / 总人数
- 例如：6人局2狼，每人初始狼概率 = 2/6 = 33%

### 信息更新规则

每当有新信息出现，更新每个人的狼概率：

**正向信号（增加狼概率）**：

- 发言逻辑矛盾
- 票型站错队
- 过度防守某人
- 行为不符合身份

**负向信号（降低狼概率）**：

- 提供有价值的分析
- 票型站对队
- 行为符合身份
- 被查验为好人（硬信息）

### 交叉验证

- 不要孤立看一个信号
- 如果 A 和 B 互相指认，至少有一个是狼
- 如果 A 疯狂保 B，他们可能是狼队友

---

## 三、决策树思维：预判三步

不要只想"我要做什么"，要想**"如果我这么做，会引发什么连锁反应"**。

### 第一步：我的行动

- 我要投票给谁 / 刀谁 / 查验谁 / 用药给谁

### 第二步：对方可能的反应

- 如果我投 A，其他人会跟票吗？
- 如果我刀 B，女巫会救吗？
- 如果我悍跳预言家，真预言家会如何应对？

### 第三步：我的应对方案

- 如果对方这样反应，我有 Plan B 吗？
- 最坏情况下，我能接受吗？

### 示例：狼人刀人决策树

```
我刀3号位（预言家）
├─ 女巫救了
│   ├─ Plan B：明天刀女巫
│   └─ 我们的悍跳继续推进
└─ 女巫没救
    ├─ 预言家出局，我们优势
    └─ 继续找女巫
```

## 四、信息管理：说什么、不说什么

### 作为好人

- **该说的**：你的分析、你的判断、你的票型理由
- **不该说的**：过度暴露神职身份（除非必要）
- **技巧**：用"我觉得"而非"我知道"（避免狼人定位你）

### 作为狼人

- **该说的**：伪装成好人的分析、带节奏
- **不该说的**：暴露队友、逻辑自相矛盾
- **技巧**：90% 真话 + 10% 关键假话（例如悍跳时的查验结果）

---

## 五、关键原则

### 1. 不要情绪化

- 被质疑时不要急于自证
- 被投票时冷静分析原因
- 狼人杀的潜规则：**好人反而更冷静**

### 2. 不要过度防守

- 过度防守 = 心虚
- 如果你是好人，简单说明身份即可
- 如果你是狼人，适度防守，不要过头

### 3. 重视票型

- 票型是最诚实的信息
- 谁投了谁，往往比发言更有价值
- 狼人很难在票型上完全隐藏

### 4. 识别套路

- 悍跳狼：查验结果过于激进
- 倒钩狼：假装分析，实际保护队友
- 自刀狼：引诱女巫交药

---

## 六、决策检查清单

每次做决策前，快速过一遍：

- [ ] 我分析了当前局势吗？
- [ ] 我区分了硬信息和软信息吗？
- [ ] 我更新了每个人的狼概率吗？
- [ ] 我预判了对方的反应吗？
- [ ] 我有 Plan B 吗？
- [ ] 我的发言会暴露关键信息吗？

---

**记住：狼人杀不是靠"背规则"，而是靠"会思考"。**
